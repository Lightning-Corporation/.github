# Lightning Corp.

Lightning Corp. builds creative tools that make professional-looking music-synchronized light shows accessible to everyone. The company began Project SYNC in 2022 with the goal of using AI to create light shows without requiring technical lighting experience.

## Project SYNC

Project SYNC is an AI-powered light show controller created by Lightning Corp. It analyzes music, separates tracks into stems such as vocals, drums, bass, and other instruments, and turns those musical elements into synchronized lighting effects.

SYNC supports WLED devices through the E1.31/sACN streaming protocol and Philips Hue fixtures. It includes beat and song-section detection, stem-based device assignments, show creation, live playback, and playlists for continuous performances.

Since its initial prototype, SYNC has evolved into a full show creation platform with lyric recognition, chorus detection, per-light stem assignments, playlist playback, and a modern interface designed for clearer show building.
